# 인지도 없는 동네, 카드가 먼저 인지한다? — 외국인 인바운드 로컬 디스커버리

제1회 AI금융빅데이터플랫폼 소비데이터 활용 분석·아이디어 공모전 제출작
(충북대학교 개인 참가 · 윤서영)

## 공모전 개요

- **주최**: AI금융빅데이터플랫폼 (BC카드 제공 데이터 기반)
- **주제**: 전국 시군구·업종별 소비데이터를 활용한 상권 분석 및 서비스·아이디어 제안
- **제공 데이터**: BC카드 전국 시군구별·업종별 카드 소비 집계 데이터 (2026년 1~6월, 성별·연령대별 이용금액·이용건수)
- **심사 기준**: 데이터 활용도·분석력 40% / 독창성·참신성 40% / 실현가능성·구체성 20%

## 아이디어 요약

리뷰·SNS는 누군가 방문하고 후기를 남겨야 비로소 생기는 후행 지표인 반면, 카드 결제는 그 즉시 데이터가 됩니다. 이 프로젝트는 **외국인 관광객의 카드 소비가 급증하기 시작했지만 아직 대중적으로 알려지지 않은 지방 상권**을 카드 데이터로 먼저 포착해, 지자체·소상공인에게는 조기 알림을, 외국인 이용자에게는 '로컬 얼리버드' 스팟 큐레이션을 제공하는 서비스를 제안합니다.

**분석 방법**
- 시군구×업종 소비 데이터를 업종별 전국 평균 대비 "상대 초과성장률"로 재정의해 스코어링 (단순 증가율은 업종 공통 계절성에 오염되기 쉬움을 확인 후 보정)
- 최소건수 필터(6개월 누적 200건·최근월 30건)를 통과한 2,111개 시군구×업종 조합 중 최종 후보 8곳 도출
- 한국관광 데이터랩(TourAPI) 외국인 방문자 통계 및 뉴스 검색으로 독립적인 외부 데이터 교차검증

**핵심 검증 결과**

| 가설 | 내용 | 판정 |
|---|---|---|
| H2 사각지대 | 후보 8곳 초과성장률이 유명 관광지·산업단지 대비 약 19~26배, 규모가 비슷한 비후보 지역 대비 약 3.8배 높음 (Mann-Whitney p<0.001) | 채택 |
| H1 선행성 | 카드 신호와 TourAPI 방문자 통계 시차상관 분석 — 8곳 중 6곳은 방문자 증가가 카드보다 먼저, 옹진군 1곳만 카드 신호가 먼저(사례 관찰) | 조건부 채택 |
| H3 지속성 | 후보 20곳 사후 확인 20/20 지속, 전국 재검증에서는 '수준 유지'만 확인(성장률 지속은 무작위 기준 이하) | 조건부 채택 |

**서비스 구조**: BC카드·네이버페이·유니온페이의 방한 외국인 결제 편의 확대 업무협약(2026.8.24) 인프라 위에서 작동하는 서비스·콘텐츠 레이어로, 신규 카드 발급 없이 조기 알림 + 로컬 큐레이션 + 첫 결제 포인트·배지를 제공합니다.

**기대 효과**: 최종 후보 8곳의 외국인 카드 소비는 6개월간 +58.2% 성장(같은 기간 전국 외국인 소비 평균 성장률의 약 18배) — 단, 이는 최소건수 필터를 통과한 조합 중 육안 검수를 거친 파일럿 규모(전국 외국인 소비의 약 0.24%)입니다.
